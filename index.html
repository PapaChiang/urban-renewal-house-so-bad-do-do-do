    計算方式：風險分數與可行性分數

    風險分數

    衡量「如果發生大地震，這個里出大事的可能性與後果有多重」。分數越高，越應該優先做耐震初評。

    風險 = 危害a × 脆弱度b × 暴露c × (1 + 0.35 × 搶救困難)

    考量了哪四件事

    • H 危害：地面會不會出問題 真實資料
      看土壤液化潛勢。里內高潛勢區的面積越大越高；中、低潛勢和圖資未涵蓋的區域也算，但分量較小（高 1.0、中 0.6、低 0.3、未涵蓋 0.3）。液化潛勢圖的 class 1、2、3 目前暫時解讀為高、中、低，還沒有確認；圖資未涵蓋的面積暫以低潛勢計分。
    • V 脆弱度：房子禁不禁得起 模擬值
      屋齡越舊越高，磚造等較不耐震的構造越多越高。屋齡占七成，構造占三成。
    • E 暴露：受影響的人有多少 真實資料
      看 65 歲以上的人數、比例，和人口密度，三者占 40%、40%、20%。高齡者逃生和避難較不容易。
    • S 搶救困難：出事後救不救得到 真實資料
      看消防搶救困難清冊的列管筆數，分四類加權（消防困難 1.0、長巷 0.6、社區 0.5、死巷 0.8）。沒有列管的里是 0。

    公式為什麼這樣定

    • 為什麼用相乘：地盤沒問題，房子再舊風險也有限；房子都很新，地盤再差也不容易出事。相乘會讓「危害、脆弱度、暴露三項都高」的里分數最高，只有一項很高的不會排到最前面。
    • 為什麼先換算成 0.1 到 1：每一項先換算成 0 到 1（去掉最極端的 1% 避免被個別里拉歪），再墊高到最低 0.1，免得某一項是 0 就把整個分數變成 0。
    • 指數 a、b、c = 0.485、0.349、0.166：代表三項的重要程度，指數越大，這項對分數高低的影響越大。所以危害最重，脆弱度次之，暴露最輕。取兩種方法的平均：一是用兩兩比較決定誰比較重要（AHP，目前的比較表是我的假設，不是專家問卷），二是看資料裡哪一項在各里差異最大、差異大的給較多權重（熵權法）。
    • 為什麼搶救困難用加成而不是相乘：它不影響地震會不會造成損害，只影響損害發生後救援得好不好，所以只當作加分：沒有列管就乘 1，最嚴重的乘 1.35。0.35 是我設定的假設值。
    • 等級：全市 456 個里依分數的自然斷點分成極高、高、中、低、極低五級。另有一條硬性規則：液化高潛勢面積占 50% 以上、而且 1974 年前建物占 30% 以上的里，一律列極高。

    可行性分數

    衡量「這個里的老屋如果要重建或都更，整體條件推起來容不容易」。它看的是里的整體條件，不是某一棟或某一個案件。

    可行性 = 0.25×街廓完整 + 0.25×公有地 + 0.20×(1−產權複雜) + 0.15×巷寬 + 0.15×(1−高齡比例)

    考量了哪五件事

    • 街廓完整度（25%）：基地能不能連成一整塊 模擬值
      街廓越完整，越容易合併規劃。
    • 公有土地比例（25%）：市府能不能拿得出地 模擬值
      公有地越多，越有機會由市府主導整合。
    • 產權複雜度（20%，越單純越好）：要說服幾個人 模擬值
      所有權人越多、越分散，取得同意越難，所以用「1 減」，複雜度越高分數越低。
    • 巷寬（15%）：施工與搶救進得去嗎 模擬值
      巷子越寬，重建施工、車輛和消防越容易。
    • 高齡比例（15%，越低越好）：出資與搬遷的難度 真實資料
      高齡住戶比例越高，通常越難負擔費用或暫時搬離，所以也用「1 減」。這是我的判斷，不是法規或研究結論。

    公式為什麼這樣定

    • 為什麼用相加（加權平均）：這幾個條件可以互相補償，例如公有地多，可以彌補產權比較複雜。所以用加權平均，不像風險分數用相乘。這是設計選擇。
    • 權重怎麼來：沒有文獻或資料支持，是我依常識排的：街廓與公有地最重要，產權次之，巷寬與高齡比例再次之。換成真實資料後權重也應該重新討論。
    • 標準化：各因子換算成 0 到 1，最後同樣墊高到 0.1 到 1。
    • 高或低：與全市中位數（）比較，不低於中位數算可行性高。
    • 四級：中位數兩側各再對半分，成為高、中高、中低、低，每級約 114 個里。

    兩個分數怎麼合成建議行動

    風險等級「極高」「高」算風險高；可行性不低於中位數算可行性高。兩個條件交叉，得到四個象限：公辦都更優先、結構補強／危老重建輔導、民間自行推動、一般追蹤。可行性只決定建議行動，不影響風險分數和排名。

    目前只有危害、暴露、搶救困難和高齡比例是真實資料，其餘都是模擬值，權重也沒有經過驗證；換成真實資料後，排名和建議行動都會改變。

    補充條件

    • 危老的基本條件：位於都市計畫範圍內的合法建築物，且不是指定的歷史、文化、藝術或紀念價值建築。
    • 補強補助：初評 R 大於 30 可申請補強方案 A 或 B，方案 C 要大於 45；最高補助工程費 85%，上限 450 萬元。住宅使用樓地板比例未達三分之二的建築不適用。
    • 啟動初評：公寓大廈要經區分所有權人過半同意，或區分所有權人會議決議。
